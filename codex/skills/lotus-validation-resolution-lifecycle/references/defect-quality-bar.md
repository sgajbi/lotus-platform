# Defect Quality Bar

Each issue must contain:

1. Evidence
- API response/error snippets
- log and observability evidence
- path to run artifact file

2. Reproduction
- clear, minimal, ordered steps
- concrete endpoint/command references

3. Behavior
- expected behavior
- actual behavior

4. Cause and Coverage
- root-cause hypothesis (if identifiable)
- why current tests missed the defect
- recommended regression tests

5. Closure Evidence
- post-fix QA run id or artifact link
- statement of checks now passing
