A portfolio workflow should not only show who is in scope.

It should show why.

That small difference changes the quality of the operating conversation.

If a review queue says a portfolio is included, the next question from a portfolio manager, supervisor, or operator is usually practical: what evidence put it there?

Was it a mandate rule?
Was it a model change?
Was it a source-owned eligibility signal?
Was the source complete enough to trust?

When the reason is hidden, users either trust the workflow blindly or leave the screen to reconstruct context somewhere else.

Good front-office workflow design keeps the source-owned selection basis attached to the action. It does not ask the UI to infer the reason. It does not let the workflow system become the source of facts.

It simply carries the evidence forward in language the user can act on.

That is not cosmetic detail.

It is how a platform becomes reviewable, supportable, and easier to challenge without breaking trust.
