# Roadmap

## Current phase

`lotus-platform` already owns active governance foundations rather than aspirational placeholders.

## Delivered foundations

- CI lane and validation governance
- central context and agent operating contract
- developer onboarding and bootstrap guidance
- shared ingress and service-addressing support
- platform automation and background-run tooling
- Lotus skill distribution and validation posture

## Ongoing tightening areas

- richer validator-backed standards coverage
- cleaner repo-to-platform documentation boundaries
- stronger reusable documentation patterns across Lotus repos
- more durable evidence and operator summaries for cross-app validation

## Intentional boundaries

- `lotus-platform` should not absorb domain-specific implementation truth
- `lotus-platform` should not replace repo-local ownership
- `lotus-platform` should not become a dumping ground for historical product strategy material that
  no longer matches current Lotus architecture
